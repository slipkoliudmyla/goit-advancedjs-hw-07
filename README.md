# ООП і TypeScript

Домашня робота 7 курсу Advanced JavaScript and TypeScript.
Основа проєкту — [шаблон GoIT](https://github.com/goitacademy/typescript-homework-module-3).

## Завдання

- [src/1.ts](src/1.ts): властивості `Student` оголошені й ініціалізовані через параметри конструктора з `public`.
- [src/2.ts](src/2.ts): `name` має доступ `public`, `department` — `private`, `salary` — `protected`. Конструктор `Manager` викликає `super` і збільшує зарплату на 10000.
- [src/3.ts](src/3.ts): інтерфейси `ICharacter` та `ISpellCaster` описують властивості й методи `Wizard`. Приклад Merlin збережено: після `levelUp()` рівень дорівнює 16.
- [src/4.ts](src/4.ts): реалізовано `Key`, `Person`, абстрактний `House` та його нащадок `MyHouse`. Двері спочатку зачинені. Правильний підпис ключа відчиняє двері, а `comeIn()` додає людину до мешканців лише за відчинених дверей.

У четвертому завданні використано назву `openDoor` з прикладу виклику та опису `MyHouse`; написання `OpenDoor` в одному реченні умови відрізняється регістром. `Math.random()` тут імітує підпис ключа для навчального сценарію і не призначений для справжніх систем доступу.

## Запуск

Потрібні Node.js і npm. У корені проєкту:

```sh
npm ci
npm run typecheck
npm run demo
```

`typecheck` перевіряє типи зі строгими налаштуваннями. `build` компілює файли з `src` у `dist`; `demo` запускає всі чотири приклади в Node.js. CommonJS у конфігурації обрано для прямого запуску результату в Node.js.

Приклади виводять дані студентки, зарплати 30000 і 40000, три повідомлення чарівника та стан будинку з відчиненими дверима й одним мешканцем. Числовий підпис ключа змінюється між запусками. Інтерфейси й модифікатори TypeScript перевіряються до запуску; `private` у цьому коді не є захистом секретних даних під час виконання JavaScript.
